# Approved brand media

This folder is reserved for approved Crystal Kizor, Studio COKA and ELEvated media.

Add a photo (e.g. architecture.jpg) here, then provide the path in src/data/chapters.ts as imageSrc: "/media/architecture.jpg".

Images are intentionally NOT substituted with unrelated stock portraits or projects. The three built-in illustrations are clearly labelled concept visuals until the correct brand assets are available.

Keep exports optimized for web (AVIF/WebP recommended where possible). Confirm usage rights and write accurate alt text before publishing.
